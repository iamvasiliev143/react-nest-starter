## Порядок работы

### Выбор места для логики

- Значение, которое следует из props или state, вычисляй при рендере. Действие по клику или отправке формы выполняй в обработчике. Эффект используй для синхронизации с внешней системой, например подпиской WebView или таймером.
- Серверные данные и мутации проводи через существующие TanStack Query и OpenAPI-клиент. Когда меняется ключ запроса или инвалидация после мутации, проверь поведение при смене параметров и ошибки.
- Для подписки, слушателя или таймера обеспечь симметричную очистку. Проверь изменение зависимостей, размонтирование и устаревшие значения в замыкании. Пользуйся `react-hooks/exhaustive-deps` и разбирай причину предупреждения перед изменением зависимостей.
- Выделяй custom hook, когда он изолирует полезный жизненный цикл или повторяемую логику. Мемоизацию подкрепляй наблюдаемой задачей производительности или требованием стабильной идентичности.
- При изменении поведения проверь его через Testing Library или Playwright в зависимости от затронутого сценария.
- Для правок только текста или стилей достаточно общих проверок.

## Результат

Зафиксируй проверенные состояния, проверку очистки подписок или таймеров и фактический результат.
