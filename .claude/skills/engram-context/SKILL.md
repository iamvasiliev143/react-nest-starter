## Порядок работы

`@sentropic/engram` индексирует исходники локально. Для известного файла или небольшого diff сразу открой исходники. Команды запускай из корня проекта, когда они помогут сузить область поиска.

1. Для незнакомого потока выполни `npm run graph:summary -- --top-hubs 3 --top-communities 3 --nodes-per-community 2`.
2. Для известного символа выполни `npm run graph:query -- --budget 600 TelegramBearer` с нужным именем. Если запроса по символу достаточно, переходи к исходникам.
3. Если файлы известны и изменение влияет на несколько модулей, выполни `npm exec -- engram minimal-context --graph .engram/graph.json --files "api/src/auth/telegram-auth.ts,web/src/api.ts"` с релевантными путями. Передай список файлов явно, чтобы команда работала без Git.
4. Если граф отсутствует или устарел относительно нужных исходников, ведущая сессия может один раз выполнить `npm run graph:update`. Команда перестраивает граф локально без обращения к модели. Если граф или зависимости недоступны, используй точечный поиск.
5. Подтверди найденные связи по исходникам и тестам. Используй только нужные результаты графа и передавай ролям общую сводку.

## Результат

Передай символы, пути, подтверждённые связи и открытые допущения. Ролям без shell достаточно сводки и ссылок на исходники.
