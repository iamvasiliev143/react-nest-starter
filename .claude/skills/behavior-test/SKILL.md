## Порядок работы

Сопоставь критерии приёмки с уровнем теста. Для HTTP и NestJS используй `npm test -w api`, для поведения React — `npm test -w web`, для связки UI и API — `npm run test:e2e`. Используй существующие фикстуры и изолированные данные. Добавь регрессионный тест, если этого требует задача или текущий набор пропускает конкретный риск.

Если задача затрагивает несколько модулей или нужно найти неизвестные зависимости, используй порядок из `.claude/skills/engram-context/SKILL.md`. При точечном изменении открой нужный код напрямую.
