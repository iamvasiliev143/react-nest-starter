## Порядок работы

Определи маршрут под `/api`, статусы, входную схему, ответ и требование авторизации. Найди потребителей в `web/` и сравни изменение с текущим контрактом. Уточни совместимость до параллельной работы frontend и backend. После изменения NestJS запусти `npm run api:types` и проверь обновление `api/openapi.json` и `web/src/api-schema.d.ts`. Проверь затронутый HTTP-сценарий через `npm test -w api` и типы клиента через `npm run typecheck -w web`.

Если задача затрагивает несколько модулей или нужно найти неизвестные зависимости, используй порядок из `.claude/skills/engram-context/SKILL.md`. При точечном изменении открой нужный код напрямую.

## Результат

Передай обновлённый контракт, влияние на потребителей и результаты проверки API и клиента.
