## Порядок работы

Перед Ready for review сверяй проверки с актуальным head SHA PR. При локальном push полный набор проверок повторяет Lefthook.

Из корня репозитория выполни `npm run lint`, `npm run format:check`, `npm run typecheck`, `npm test` и `npm run build`. Запускай каждую проверку независимо от результата предыдущей.

Если изменился пользовательский сценарий и доступен подходящий браузер, выполни `npm run test:e2e`.

## Результат

Сообщи результат каждой команды и первую ошибку, с которой можно начать исправление. Перечисли проверки, которые пропустил, с причинами.
