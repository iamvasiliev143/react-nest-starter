## Порядок работы

Сверь запрос с текущим поведением в коде и переданными материалами. Запиши цель, пользователей, правила доступа, основной и пограничные сценарии, наблюдаемые критерии приёмки и открытые решения. Для фичи через React и NestJS укажи границы `web/` и `api/` и отдельно предложи HTTP-контракт. Для точечной правки достаточно короткого списка критериев.

## Результат

Передай итог `business-analyst`, `product-manager` или техлиду по текущей задаче.
