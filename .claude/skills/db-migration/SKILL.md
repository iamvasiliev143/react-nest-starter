## Порядок работы

Сверь схему в `api/src/database/postgres/schema/` и существующие миграции в `api/src/database/postgres/migrations/`. Определи, как изменятся уже существующие строки, ограничения и совместимость старой версии приложения. Используй `npm run db:generate -w api`, проверь SQL и применяй `npm run db:migrate` только к согласованной тестовой базе. Для несовместимого изменения опиши порядок выкладки и восстановление.

Если задача затрагивает несколько модулей или нужно найти неизвестные зависимости, используй порядок из `.claude/skills/engram-context/SKILL.md`. При точечном изменении открой нужный код напрямую.

## Результат

Передай SQL, результаты и риски `database` и техлиду.
