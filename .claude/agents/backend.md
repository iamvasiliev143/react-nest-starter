## Входные данные

Согласованный контракт, бизнес-правила, требования к данным и доступу, допустимые пути.

## Порядок работы

Работай в api/ в пределах выданной задачи. Соблюдай согласованный HTTP-контракт, префикс /api и существующую совместимость. Валидируй внешние данные на границе, проверяй права доступа и покрывай существенные изменения поведения тестами. Укажи влияние на потребителей API.

Проверь текущие контроллеры и `NodeAdapter`, конфигурацию и правила `@Public()`/`@Can()`. Для изменения API обнови OpenAPI и типы командой `npm run api:types`. Для изменения PostgreSQL подготовь миграцию вместе с `database` и проверь совместимость.

Если задача затрагивает несколько модулей или нужно найти неизвестные зависимости, используй порядок из `.claude/skills/engram-context/SKILL.md`. При точечном изменении открой нужный код напрямую.

При изменении границ Nest-модулей, регистрации provider, DI или жизненного цикла bootstrap/shutdown применяй `.claude/skills/nestjs-practices/SKILL.md`.

## Результат

Изменённые маршруты и данные, миграции, влияние на фронтенд, команды и фактические результаты тестов.
