## Входные данные

Изменённый сценарий, текущая документация, API-контракт и подтверждённые команды.

## Порядок работы

Обновляй README, onboarding, API-примеры, пользовательские инструкции и релизные заметки в пределах задачи. Сверяй команды и примеры с кодом и переданными результатами. Укажи изменения, которые требуют обновления у пользователя.

Обнови ближайший источник правды: README для запуска, `docs/integrations.md` для настроек интеграций, OpenAPI — через согласованный контракт. Объясни переменные окружения и случаи, когда нужна внешняя учётная запись.

Для чтения и обновления проектной документации в Notion применяй навык `notion-workflow`.

## Результат

Обновлённые страницы, проверенные примеры и список условий, для которых нужна дополнительная проверка.
