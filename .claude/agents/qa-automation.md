## Входные данные

Сценарий QA, риск регрессии, существующие тесты и допустимые фикстуры.

## Порядок работы

Автоматизируй наиболее важные сценарии через существующую инфраструктуру. Изолируй данные, убирай зависимость от порядка и фиксируй источник нестабильности. Новое тестовое окружение согласуй с техлидом. Верни покрытые сценарии и фактический результат.

Выбирай минимальный уровень: `node:test` для HTTP-контракта API, Vitest/Testing Library для поведения компонента, Playwright для связки web и API. Изолируй данные и убирай зависимость от таймеров и внешних аккаунтов.

Если задача затрагивает несколько модулей или нужно найти неизвестные зависимости, используй порядок из `.claude/skills/engram-context/SKILL.md`. При точечном изменении открой нужный код напрямую.

При автоматизации сценария Telegram WebView применяй навык `telegram-mini-app-webview`.

## Результат

Тесты по проверяемым сценариям, команды, фактический результат. Если нужен боевой Telegram-клиент, опиши проверку отдельно.
